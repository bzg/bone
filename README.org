BONE is an email-driven report tracker -- see the [[docs/bone-manual.org#principles][principles]].

BONE monitors IMAP mailboxes and Maildirs, classifies incoming emails
into sources by header matching, detects report types from subject
tags, applies commands from email bodies, and manages roles per
source.

BONE reports can be read with other tools:

- As a CLI based on [[https://junegunn.github.io/fzf/][fzf]]: [[https://codeberg.org/bzg/gnaw][gnaw]]
- As a standalone GNU Emacs tool: [[https://codeberg.org/bzg/gnaw.el][gnaw.el]]
- Via GNU Emacs [[https://gnus.org][Gnus]]: [[https://codeberg.org/bzg/gnus-gnaw][gnus-gnaw]]
- Via GNU Emacs [[https://notmuchmail.org/notmuch-emacs/][notmuch]]: [[https://codeberg.org/bzg/notmuch-gnaw][notmuch-gnaw]]
- Via GNU Emacs [[https://djcbsoftware.nl/code/mu/mu4e.html][mu4e]]: [[https://codeberg.org/bzg/mu4e-gnaw][mu4e-gnaw]]

The =gnus-gnaw=, =notmuch-gnaw= and =mu4e-gnaw= front-ends are
unmaintained proofs of concept.

* Quick start

#+begin_src sh
# 1. Copy and edit the config (minimal: one mailbox, one source)
cp config.edn.minimal config.edn
bb test-config              # validate it

# 2a. Run once (fetch new emails, expire, exit)
clj -M:run

# 2b. Run in watch mode (IMAP IDLE or Maildir, stays running)
clj -M:run -- --watch

# 2c. Or build an uberjar and run it (production)
bb build-jar                # produces target/bone.jar + bin/bone wrapper
bin/bone --watch

# 3. Export reports to public/
bb export                   # incremental (skips if nothing changed)
bb export --force           # full rebuild, ignore timestamps

# 4. Send notification emails
bb notify --dry-run         # preview without sending
bb notify

# 5. Run tests
clj -M:test
#+end_src

* Configuration

BONE reads =./config.edn= (override with =-c <path>= or =BONE_CONFIG=).
Its two required sections are =:mailboxes= (where the mail comes from:
IMAP or Maildir) and =:sources= (which mail belongs to which tracker:
matched by =List-Id=, alias or delivery address).

- =config.edn.minimal= is the smallest working config.
- =config.edn.example= is the annotated reference of every key.
- The manual's [[docs/bone-manual.org#deploying-bone][Deploying BONE]] chapter documents each section: mailboxes,
  sources, periods, expiry, notifications, theme, logging, production
  setup.
- Its [[docs/bone-manual.org#cli-reference][CLI reference]] lists every =bb= task and flag.
